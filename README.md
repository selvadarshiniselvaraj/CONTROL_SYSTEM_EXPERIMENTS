# Control Systems Experiments

This repository contains my **Control Systems laboratory experiments** implemented using **MATLAB and Simulink**.

The experiments cover fundamental concepts of control systems, including system modeling, transfer functions, time-domain analysis, stability, controllers, and simulation.

## 📚 Topics Covered

* Control system modeling
* Transfer functions
* Block diagram representation
* Time-domain analysis
* Step and impulse response
* First-order and second-order systems
* Stability analysis
* Root Locus
* Bode Plot
* Nyquist Plot
* PID Controller
* Feedback control systems
* MATLAB simulations
* Simulink implementations

## 🛠️ Tools Used

* MATLAB
* Simulink
* Control System Toolbox

## 🎯 Objectives

The main objectives of these experiments are to:

1. Understand the fundamental principles of control systems.
2. Analyze the behavior of different control systems.
3. Model systems using transfer functions and block diagrams.
4. Study system stability and performance.
5. Design and analyze controllers.
6. Implement control-system concepts using MATLAB and Simulink.
7. Gain practical experience in simulation and analysis.

## 📊 Results

The repository includes MATLAB programs, Simulink models, plots, and simulation results wherever applicable.

Each experiment contains the required **code, model files, and results** for easy reference and reproduction.
